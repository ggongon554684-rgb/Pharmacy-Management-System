Overview — database and data path

Use this tab for the “how it connects to the database” and “input → system → database → output” segments of a short presentation.

MySQL connection

Laravel reads DB_HOST, DB_DATABASE, DB_USERNAME from .env and connects through config/database.php (driver mysql).

.env.example is laravel).

Key tables (examples)

  • users — accounts; roles via Spatie permission tables
  • patients, products — master data for POS
  • inventory_batches, stock_movements — stock truth and traceability
  • purchase_orders — procurement lifecycle
  • sales, sale_line_items — checkout
  • audit_logs — who / what / when for sensitive actions

Data path

Input Browser forms & buttons (Blade views)
→
System HTTP routes → controllers → validation → Eloquent models
→
Database MySQL tables; transactions for multi-row writes
→
Output Updated pages, lists, receipts, reports, audit entries
